# Salgados da Paulinha

Site estático (HTML + CSS + JS puro, sem dependências). Abra `index.html` no navegador ou publique a pasta em qualquer hospedagem (GitHub Pages, Netlify, Vercel).

## O que editar
- **`script.js` (topo):** número do WhatsApp (`WHATSAPP`, só dígitos com 55 + DDD) e lista de produtos/preços (`PRODUTOS`).
- **`index.html`:** troque `[BAIRRO]`, `[CIDADE]`, `[ENDEREÇO]`, `[NÚMERO]`, `[INSTAGRAM]`, preços dos kits, horários e o endereço do mapa (`src` do iframe).
- **Fotos:** cada bloco `.ph` tem a descrição da foto ideal. Troque por `<img src="fotos/coxinha.webp" alt="..." loading="lazy">` (use WebP, ~1200px de largura).
